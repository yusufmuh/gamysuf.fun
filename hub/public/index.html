        Apakah hadiah dari game online bisa ditukar?

        Tidak. Di arcade online kamu mendapat kartu koleksi digital dan XP. Hadiah fisik (produk dan voucher) hanya diberikan di booth Bpedia saat event, menggunakan perangkat booth yang dijaga petugas.

        Progres saya tersimpan di mana?

        Di server Gamysuf, terhubung ke perangkat ini lewat cookie. Buka Atur profil untuk menyalin kode pemulihan, lalu masukkan kode itu di perangkat lain untuk memindahkan progres.

        Bisa main di HP, tablet, atau laptop?

        Bisa. Tata letak mengikuti ukuran layar, termasuk ketika HP diputar atau layar lipat dibuka. Gunakan tombol sentuh di HP dan tablet, atau mouse dan keyboard di laptop. Progres pindah perangkat memakai kode pemulihan di profil.

        Bagaimana mengatur suara dan animasi?

        Suara mulai setelah kamu menyentuh tombol permainan. Tombol suara tersedia di setiap game. Animasi mengikuti pengaturan kurangi gerakan di perangkatmu.

        Bagaimana streak dihitung?

        Main minimal sekali setiap hari (WIB). Melewatkan satu hari membuat streak kembali ke 1 saat kamu main lagi. Rekor terbaik tetap tersimpan.

        Saya di booth Market-In 6.0. Bagaimana cara main dengan hadiah asli?

        Misi booth diumumkan langsung oleh petugas Bpedia. Setelah misimu selesai, petugas membuka Gacha Pop atau Grand Line Desire di perangkat booth. Hasilnya berupa kode GP- atau HP- untuk ditunjukkan saat klaim. Info lengkap di halaman Market-In 6.0.

        Saya petugas booth. Bagaimana mengaktifkan mode resmi?

        Buka dashboard game di perangkat booth dan masuk dengan PIN petugas. Hanya perangkat yang sudah masuk yang memakai stok asli dan mode resmi; pengunjung online tetap di mode demo.

        Akan ada game baru?

        Ya. Arcade ini punya slot untuk game berikutnya. Saat game baru rilis, kartunya akan muncul di bagian Pilih Arena.
