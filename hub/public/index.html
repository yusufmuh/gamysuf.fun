          PANDUAN

          Cara kerja Gamysuf Arcade

          1. 1

            Pilih arena

            Tiga game booth Bpedia siap dimainkan langsung di browser, tanpa unduh dan tanpa bayar.

          2. 2

            Main & kumpulkan

          3. 3

            Naik level

            Selesaikan misi harian, jaga streak, dan buka lencana untuk naik di papan peringkat.

          4. 4

            Datang ke booth

            Hadiah fisik hanya diberikan di booth Bpedia saat event, bersama petugas dan mode resmi.

          Main adil, jelas aturannya

          • Hasil setiap permainan diacak oleh server game. Browser hanya menampilkan animasi.
          • Versi online selalu mode demo: stok hadiah asli di booth tidak berkurang.
          • XP permainan dihitung sampai 60 permainan per hari; setelah itu tetap bisa main untuk koleksi.
          • Tidak ada pembelian, top-up, atau persentase peluang tersembunyi.

          Apakah hadiah dari game online bisa ditukar?

          Tidak. Di arcade online kamu mendapat kartu koleksi digital dan XP. Hadiah fisik (produk dan voucher) hanya diberikan di booth Bpedia saat event, menggunakan perangkat booth yang dijaga petugas.

          Progres saya tersimpan di mana?

          Di server Gamysuf, terhubung ke perangkat ini lewat cookie. Buka Atur profil untuk menyalin kode pemulihan, lalu masukkan kode itu di perangkat lain untuk memindahkan progres.

          Kenapa tampilan game terasa kecil di HP?

          Ketiga game dirancang untuk layar booth yang lebar. Putar HP ke posisi mendatar atau main dari laptop untuk pengalaman terbaik.

          Bagaimana streak dihitung?

          Main minimal sekali setiap hari (WIB). Melewatkan satu hari membuat streak kembali ke 1 saat kamu main lagi. Rekor terbaik tetap tersimpan.

          Saya petugas booth. Bagaimana mengaktifkan mode resmi?

          Buka dashboard game di perangkat booth dan masuk dengan PIN petugas. Hanya perangkat yang sudah masuk yang memakai stok asli dan mode resmi; pengunjung online tetap di mode demo.

          Apa itu gelar pemain?

          Gelar naik bersama level: Pendatang Baru (Lv 1), Pemburu Hoki (Lv 3), Kolektor Muda (Lv 5), Bintang Arcade (Lv 8), Master Kapsul (Lv 12), dan Legenda Bpedia (Lv 16). Gelarmu tampil di profil dan papan peringkat.

          Akan ada game baru?

          Ya. Arcade ini punya slot untuk game berikutnya. Saat game baru rilis, kartunya akan muncul di bagian Pilih Arena.
